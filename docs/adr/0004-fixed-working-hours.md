# Фиксированные рабочие часы слотов

Status: accepted. Date: 2026-10-14.

## Context

Слоты генерируются на лету (`build_slots_for_date`), поэтому нужен детерминированный дневной диапазон. В контракте часов не было — клиенты не могли предсказать, сколько слотов вернётся за день.

## Decision

Дневной диапазон фиксирован для v1: `9:00–18:00` по `Europe/Moscow`, слоты по сетке `:00/:30` (ADR-0001) — ровно 18 слотов на день. Настраиваемого расписания на Owner нет.

## Consequences

Плюс: генерация детерминирована, UI и тесты опираются на константу (тест фиксирует 18 слотов). Минус: вечерние/утренние звонки вне диапазона невозможны без изменения решения; смена диапазона считается breaking change для клиентов.
