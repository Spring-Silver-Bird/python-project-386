# Окно бронирования 14 дней

Status: accepted. Date: 2026-10-09.

Бронирование и просмотр слотов — только в календарных днях `[today, today + 14 дней]` по `Europe/Moscow`, сравнение по дате старта слота (решение #5: единый механизм вместо окна по моменту). Слот в прошлом (старт ≤ now) недоступен для просмотра как свободный и отклоняется при бронировании. Окно считается от текущей даты, чтобы старые слоты не висели доступными.
