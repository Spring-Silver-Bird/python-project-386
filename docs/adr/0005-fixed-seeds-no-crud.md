# Фиксированные сиды v1, без CRUD владельцев и типов

Status: accepted; partially superseded by ADR-0007. Date: 2026-10-14.

## Context

Для v1 нужен предсказуемый стартовый набор без управления пользователями: один Owner (Алекс) и один EventType («Звонок 30 минут», `duration_minutes = 30`). Полноценный CRUD напрашивается сам, но тянет за собой авторизацию, которой в скоупе нет.

## Decision

Сиды фиксированы в коде; CRUD для Owner/EventType в v1 не вводится (см. Out of scope спеки #8). Хранилище в памяти легально для v1.

## Consequences

Плюс: нет поверхности для управления данными, демо и тесты детерминированы. Минус: новый владелец/тип встречи — только правкой кода и сидов; появление CRUD — отдельным решением с пересмотром модели доступа.

Update 2026-10-20: ADR-0007 добавил список и создание EventType для сценария владельца. Owner CRUD и edit/delete EventType остаются вне v1.
